# HR Workforce Analytics Dashboard

An end-to-end Power BI dashboard built to help HR teams monitor workforce health, spot risk areas early, and support data-driven people decisions.

## 📊 Overview

This project transforms raw HR data into a single, interactive dashboard that surfaces the metrics leadership actually needs to act on — who's ready for advancement, who's at risk of leaving (or being let go), how satisfied employees feel, how roles are distributed, and where overtime is piling up.

## 🔑 Key Metrics Tracked

- **Promotion Eligibility** — identifies employees who meet the criteria for advancement, helping HR plan career progression proactively
- **Retrenchment Potential** — flags employees at higher risk of layoff based on workforce indicators, supporting early, informed planning
- **Employee Job Satisfaction** — visualizes satisfaction trends across teams and demographics to highlight engagement gaps
- **Job Roles Distribution** — breaks down headcount across roles and departments for a clear view of org structure
- **Overtime Analysis** — tracks overtime patterns to catch burnout risk and workload imbalances before they escalate

## 🛠️ Tools Used

| Tool | Purpose |
|------|---------|
| **Power BI** | Dashboard design and interactive visualization |
| **DAX** | Custom measures and calculated metrics |
| **Power Query** | Data cleaning, shaping, and transformation |
| **Excel** | Source data preparation and validation |

## 💡 Why This Matters

Traditional HR reporting tends to be reactive — problems surface after they've already become costly. This dashboard flips that by giving HR teams a forward-looking view: catching disengagement, overtime strain, and attrition risk while there's still time to intervene.

## 🚀 Getting Started

1. Clone or download this repository
2. Open the `.pbix` file in Power BI Desktop
3. Refresh the data connection to point to your own HR dataset
4. Explore the report pages and filter by department, role, or time period
